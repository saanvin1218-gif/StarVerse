CIRCLE OF NUMBERS
A Mathematical Art Project Using Python

Project Description:
Circle of Numbers is a Python project that combines mathematics, geometry, and programming to create beautiful patterns using straight lines arranged around a circle.

How It Works:
1. The program places equally spaced points around a circle.
2. It uses a multiplication rule to determine which points to connect.
3. Straight lines connect the points to create geometric patterns.
4. The animated version draws the lines gradually and allows the user to explore different settings.

Technologies Used:
- Python
- Tkinter — for the application window, buttons, sliders, and drawing area
- Math module — for mathematical calculations and point positions

How to Run:
1. Make sure Python is installed on the computer.
2. Open the Python IDLE application.
3. Open `Circle_of_Numbers.py`.
4. Select Run → Run Module (or press F5).
